# テーブル対応チェックシート

## 目的
ZARMS上で全テーブル全カラムの閲覧・編集導線を揃えるための進捗管理シートです。
削除操作は提供しない方針のため、本シートの判定対象は「閲覧・編集・保存・再読込」のみとします。

## 判定ルール
- 閲覧: 一覧または詳細で値が確認できる
- 編集: UIで入力可能
- 保存: DBへ反映される
- 再読込: 再表示後も反映が維持される
